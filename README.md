# Airline-Flight-Data-Analysis
Airline flight data analysis project using Python, SQL, and Power BI to create dashboards, visualize trends, and generate KPIs.


## 📌 Project Overview

This repository contains a **data analytics project** on **airline flight data** sourced from **Kaggle**.

The goal is to clean, analyze, and visualize flight data, create KPIs, and build interactive dashboards to uncover trends and insights.

This project serves as a **learning exercise** and also a **portfolio piece for recruiters** showcasing skills in **Python, SQL, and Power BI**.

## 🛠️ Tools & Libraries Used

**Python**: pandas, NumPy, matplotlib, seaborn, plotly

**SQL**: For querying and extracting meaningful data from structured datasets

**Power BI**: For creating dashboards, KPIs, and interactive visualizations

## 🧹 Data Cleaning & Analysis

Handled **missing values, duplicates, and inconsistent data**

Performed **data transformations** and feature engineering

Conducted exploratory data analysis **(EDA)** to identify patterns and trends

## 📊 Visualizations & Dashboards

Created **charts, graphs, and KPIs** to understand airline performance

Built **Power BI dashboards** for interactive exploration of trends

Visualized **flight delays, on-time performance, busiest routes, and more**

## 🎯 Key Outcomes

Interactive **Power BI dashboards**

Identified **trends in flight operations**

Generated **key performance indicators (KPIs)** for airline performance analysis

## 📁 Dataset

Sourced from **Kaggle**

Contains airline flight records, including delays, routes, and operational metrics

Original dataset not included in the repo (optional: can add if size allows)

## 🚀 How to Run

1. Clone the repository:

git clone https://github.com/YourUsername/airline-flight-data-analysis.git


2. Install Python dependencies:

pip install -r requirements.txt


3. Open the Jupyter notebooks in Python folder to explore analysis.

4. Use the SQL scripts in **SQL** folder to query datasets.

5. Open Power BI files in **PowerBI** folder to view dashboards.
